# Land-lord-manager

Deterministic property management app built with Next.js + Tailwind and Supabase/PostgreSQL schema.

## Run

```bash
npm install
npm run dev
```

## Core features shipped

- **One-Time Setup dashboard** for template builder, bulk unit insertion, and building vault.
- **Logic-tree maintenance flow** with required troubleshooting acknowledgment before submitting tickets.
- **Automatic routing mode toggle** to simulate staff-assigned vs landlord DIY routing.
- **Tax-ready ledger concepts** including required receipt capture before close and Schedule E summary view.
- **Supabase schema migration** with users, buildings, templates, units, responsibility matrix, and work orders.
